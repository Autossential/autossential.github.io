Culture Scope

A container that allows you to run a set of activities over a different culture.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Culture | The desired culture, eg.: en-US, pt-BR, jp-JP, etc. | :ballot_box_with_check: |
