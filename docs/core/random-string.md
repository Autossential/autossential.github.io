Random String
</h1>

Generates a random string based on a format pattern.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Custom Characters | Additional characters used when the '?' placeholder is present. |  |
| Format | Pattern that defines the generated string. Placeholders: 'a' lowercase, 'A' uppercase, '0' digit, '*' any alphanumeric, '?' custom characters, '\\' escape. | :ballot_box_with_check: |
| Result | The generated random string. |  |
