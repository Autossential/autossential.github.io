Add Range To Collection
</h1>

Adds a set of items to the specified collection.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Collection | The collection to be modified. | :ballot_box_with_check: |
| Items | The items to be added to the collection. | :ballot_box_with_check: |
