Unzip
</h1>

Extracts files and folders from a zip archive.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Extract To | The folder where the archive contents will be extracted. | :ballot_box_with_check: |
| Overwrite | If true, existing files will be overwritten during extraction. |  |
| Zip File Path | The path to the zip archive to extract. | :ballot_box_with_check: |
