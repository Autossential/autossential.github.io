Increment/Decrement
</h1>

Adjusts an integer variable by incrementing or decrementing it with a specified value.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Operation | Operation to be performed. | :ballot_box_with_check: |
| Value | Value to add or subtract to variable. Must be equal or greater than 1. | :ballot_box_with_check: |
| Variable | The variable to be adjusted. | :ballot_box_with_check: |
