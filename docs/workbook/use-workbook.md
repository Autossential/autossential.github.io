Use Workbook
</h1>

Opens a workbook and share its instance across the child activities.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Password | The password required for open the workbook if it is password-protected. |  |
| Sheet Names | Returns the list of sheet names contained in the workbook. |  |
| Workbook Path | The path to the workbook. | :ballot_box_with_check: |
