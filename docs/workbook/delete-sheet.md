Delete Sheet
</h1>

Deletes a specified worksheet from the workbook. Use this activity when you need to remove unwanted sheets from the workbook.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Sheet Name | Name of the worksheet to be deleted. This property is required and the sheet must exist in the workbook. | :ballot_box_with_check: |
