Read Cell
</h1>

Reads a cell value in the specified sheet and cell address.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Cell Address | The cell address the value should be read from. | :ballot_box_with_check: |
| Value | The value read from the cell. |  |
| Sheet Name | The sheet containing the cell that will be read from. | :ballot_box_with_check: |
