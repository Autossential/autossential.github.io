Rename Sheet
</h1>

Renames an existing worksheet in the workbook. Use this activity when you need to change the name of a specific sheet.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| New Sheet Name | New name for the worksheet. This property is required and must be unique within the workbook. | :ballot_box_with_check: |
| Sheet Name | Current name of the worksheet to be renamed. This property is required and the sheet must exist in the workbook. | :ballot_box_with_check: |
