Freeze Panes
</h1>

Freezes specified rows and columns in a worksheet, keeping them visible while scrolling through the rest of the sheet.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Columns to Freeze | Specifies the number of columns to freeze from the left. If set to 0, no columns will be frozen. | :ballot_box_with_check: |
| Rows to Freeze | Specifies the number of rows to freeze from the top. If set to 0, no rows will be frozen. | :ballot_box_with_check: |
| Sheet Name | The name of the worksheet where the panes will be frozen. | :ballot_box_with_check: |
