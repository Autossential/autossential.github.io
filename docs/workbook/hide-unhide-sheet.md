Hide/Unhide Sheet
</h1>

Hides or unhides a specified worksheet in the workbook.

## Properties

| Name | Description | Required |
|------|-------------|:--------:|
| Action | Specifies the action to perform on the worksheet. Select Hide to make the sheet invisible, or Unhide to make it visible again. |  |
| Sheet Name | The name of the worksheet to hide or unhide. | :ballot_box_with_check: |
